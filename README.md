# Lijing Liu — research publications

Static academic website: https://liulijing1.github.io/

Selected first-author publications with readable HTML summaries, scholarly citation metadata, JSON-LD, BibTeX, sitemap and crawler access rules. All paper pages link to the original DOI. The AI publishing paper is explicitly labelled as an unreviewed preprint.

## Publish

Use the public repository `liulijing1.github.io`. In Settings → Pages select Deploy from a branch → main → /(root).

## Update

Edit build_site.py and run `python3 build_site.py`. Verify new claims and publication status against the original paper before publishing. Publisher content retains its original copyright and licence.
